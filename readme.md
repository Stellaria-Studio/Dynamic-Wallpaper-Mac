# 动态壁纸 使用说明

## 快速开始

1. 打开 `VideoWallpaper.app`
2. 将 MP4/MOV/M4V 视频文件放入「壁纸素材」文件夹
3. 应用自动检测并开始轮换播放

提示：首次打开如果提示安全风险，前往 **系统设置 > 隐私与安全性 > 仍要打开**

---

## 控制面板

点击菜单栏图标 ▫ 选择「显示面板」，或按 `Cmd+Shift+P` 打开控制面板。

### 折叠状态
- ⚙ 播放设置 — 展开/收起高级控制
- 🔊 / 🔇 — 静音开关
- 📂 — 打开壁纸素材文件夹

### 展开状态
点击「⚙ 播放设置」展开完整面板：

**播放控制**
- ◀ 上一张 / ▶ 下一张 / ⏸ 暂停
- 模式：循环 / 顺序 / 随机
- 画质：1080p / 原画 / 4K
- 帧率：自动 / 30fps / 60fps（30fps 更省电）

**播放列表**
- 每个视频前有复选框 ☑
- 取消勾选 = 跳过此视频（不删除文件）
- 勾选状态自动保存，重启不丢失
- 列表可滚动，视频再多也不占空间

---

## 快捷键

| 快捷键 | 功能 |
|--------|------|
| `Cmd+Shift+N` | 下一张 |
| `Cmd+Shift+B` | 上一张 |
| `Cmd+Shift+H` | 隐藏/显示壁纸 |
| `Cmd+Shift+P` | 显示/隐藏面板 |
| `空格` | 暂停/继续 |

---

## 菜单栏

点击菜单栏图标可快速操作：
- 下一个 / 上一个
- 画质切换
- 暂停 / 继续
- 音频开关
- 隐藏壁纸 / 显示面板
- 播放模式切换（循环 / 顺序 / 随机）
- **播放列表** — 完整管理每个视频的开/关
- 状态显示（电池、温度等）
- 打开视频文件夹

---

## 自适应功能

应用会自动响应系统状态：

| 场景 | 行为 |
|------|------|
| 切换电池供电 | 自动降至 1080p 省电 |
| 温度过高 | 暂停壁纸播放 |
| 有应用全屏 | 暂停壁纸 |
| 休眠前 | 暂停播放，唤醒后恢复 |
| 专注模式 | 状态栏显示 |

## 目录结构

```
动态壁纸/
├── VideoWallpaper.app    ← 应用（双击运行）
├── WallpaperApp/         ← 源代码
├── 壁纸素材/             ← 放入你的视频文件
└── 使用说明.md           ← 本文件
```

如有问题，检查「壁纸素材」文件夹中是否有支持的视频文件（MP4/MOV/M4V/AVI/MKV）。
